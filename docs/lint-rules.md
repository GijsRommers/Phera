## `syntax-error`

Group: `syntax`. Enabled by default. 

Report the first source error at the selected PHP language level.

Before

```php
<?php
echo ;
```

After

```php
<?php
echo 'Hello';
```

## `loop-runs-once`

Group: `suspicious`. Opt-in. 

Detect a loop whose body exits unconditionally on the first iteration.

Before

```php

```

After

```php

```

## `unreachable-statement`

## `switch-fallthrough`

Group: `suspicious`. Opt-in. 

Require a comment or an explicit exit between nonempty cases.

Before

```php

```

After

```php
switch ($n) { case 1: a(); break; case 2: b(); }
```
