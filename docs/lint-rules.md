## `syntax-error`

Group: `syntax`. Enabled by default.

Report the first source error at the selected PHP language level.

Before

```php
<?php
echo ;
```

After

```php
<?php
echo 'Hello';
```

## `null-coalescing`

Group: `modernize`. Opt-in. Safe fix on a single line without comments.

Use ?? for an isset ternary that returns the checked variable.

Before

```php

```

After

## `null-coalescing-assignment`

Group: `modernize`. Opt-in. Safe fix on a single line without comments.

Use ??= when assigning a null-coalescing expression back to its variable.

```php

```

After

```php

```

## `nullsafe-operator`

Group: `modernize`. Opt-in. Unsafe fix. An undefined variable is read once and the guarded call must be a direct dereference.

Use ?-> for a method call guarded by a null check.

Before

```php

```

After

```php
$value = $a?->read();
```

