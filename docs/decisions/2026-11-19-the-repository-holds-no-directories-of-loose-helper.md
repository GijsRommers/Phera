# The repository holds no directories of loose helper scripts

- Date: 2026-11-19
- Area: Tools
- Decided by: Owner

## Decision

The repository holds no directories of loose helper scripts. A helper worth keeping is a Rust test or a command of the tooling crate; a one-off stays outside the repository. Decisions go into this file, and the README is updated with every change a user can see.

## Why

The owner reads the repository to follow the project.
