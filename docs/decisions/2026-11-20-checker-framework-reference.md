# Measure projects with their PHPStan configuration

- Date: 2026-11-20
- Area: Tools
- Decided by: Design

## Decision

Score a project against its supplied PHPStan configuration. Measure the
large Symfony application with its Doctrine, Symfony, and strict-rules
configuration, using a service map generated by Symfony in an isolated
copy. Report the core-rule counts for the same source alongside it.

## Why

Core PHPStan cannot see reads and writes through Doctrine's metadata.
Framework extensions and project rules change what the project treats as
a finding. Both measurements are needed to show the effect.

## Turned down

Deleting diagnostics from the core results by identifier or counting the
core findings on ORM-mapped properties as misses against the project rules.
