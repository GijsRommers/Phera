# Explained differences with PHPStan 2.3.6

The corpus is checked independently at levels 0 and 1. Every differing line set
has an exact row below. The comparison script validates filename, level and both
sets, so an old explanation cannot silently approve a new line or changed result.
Phera's `.expect` files are semantic expectations; `.phpstan` files are regenerated
PHPStan observations. An empty set means no reported lines.

The requested levels intentionally differ from PHPStan's adoption levels. Cases
outside the requested rule set are retained rather than removed from the corpus.
Where runtime semantics settle the issue, targeted programs were run with
`/opt/homebrew/bin/php -n` (PHP 8.5.12); no fixture with a random/infinite loop was
executed. The checker itself never runs PHP. Oracle examples and results are below.

## PHP 8.5 oracle observations

| Program | Exit | Observation |
| --- | --- | --- |
